# Документация

Этот каталог есть технический источник истины платформы. Он написан для того, кто строит `sting`, и
для того, кто хочет понять, как это работает, прежде чем доверить этому контракт. Документы отвечают
на один вопрос: как это устроено и почему именно так.

## 2. Что такое `sting` в трёх предложениях

`sting` вырос из одного статического анализатора для **Tolk** в платформу с четырьмя контурами, и
несут её 60 крейтов в workspace.

| Контур | Что делает |
|---|---|
| security | находит дефекты в исходниках Tolk и подтверждает их в настоящем TVM |
| abi-layer | извлекает нормализованную схему контракта из Tolk, Tact и FunC и отдаёт её через HTTP |
| scamcheck | выдаёт рисковые сигналы для жетонов и коллекций подарков |
| foundation | компилятор Tolk, эмулятор, доступ к цепи — общие для остальных трёх |

Все четыре собираются одной командой, гоняются одним гейтом и делят одну инженерную дисциплину.

Ни один не опубликован: удалённый репозиторий не подключён, версия `0.0.0`, публикация выключена.

## 3. Сборка и гейт

```
cargo build --workspace --all-targets
make pr
```

`make pr` — весь гейт: форматирование, clippy с запретом предупреждений, лицензии и уязвимости,
орфография, rustdoc, механические правила документации, выведенные числа, тесты и doctests. CI гонит
те же цели, а не свою копию.

Части тестов нужен внешний артефакт, и без него они **пропускаются, а не падают**
([`TESTING.md`](./TESTING.md) §6):

```
$env:STING_LIBEMULATOR_PATH = "vendor\libemulator\libemulator.dll"   # PowerShell
export STING_LIBEMULATOR_PATH=vendor/libemulator/libemulator.so      # bash
```

Доступ к цепи идёт по анонимному тарифу и не требует ничего; `.env.example` говорит, что дали бы два
ключа toncenter и почему ни один клиент их пока не шлёт.

## 4. По одной точке входа на контур

Статический анализ исходника Tolk:

```
cargo run -p sting-cli -- lint corpus/clean/acton-contracts/counter/
cargo run -p sting-cli -- explain AC
cargo run -p sting-cli -- bench --update-baseline
```

`lint` печатает находки так, как это делает компилятор: строку исходника, стрелку под точным
диапазоном колонок и строку `= help:` с конкретной рекомендацией. `explain` печатает калиброванный
профиль детектора, включая замеренную точность и известные границы, в том числе неудобные. `bench`
пересчитывает precision и recall по всему корпусу и сверяется с закоммиченным снимком.

Извлечение схемы контракта:

```
cargo run -p sting-abi-cli -- extract corpus/clean/acton-contracts/counter/Counter.tolk
cargo run -p sting-abi-cli -- dictionary-probe <адрес>
cargo run -p sting-abi-cli -- coverage-report --db coverage.sqlite3
```

`extract` даёт одну и ту же нормализованную схему, на каком бы из трёх языков ни был исходник.
`dictionary-probe` не читает исходника вовсе: тянет настоящие code и data по адресу и зовёт каждый
известный method id через настоящую виртуальную машину — так распознаётся контракт, исходника
которого нет ни у кого.

Рисковые сигналы жетона и коллекции подарков:

```
cargo run -p sting-scamcheck -- <адрес-жетона>
cargo run -p sting-scamcheck --bin gift_trust_check -- <адрес-коллекции> --domain <домен>
```

Проверка домена не гипотетическая: имитация официального хоста подарков через дефис распознаётся
тайпсквотом на расстоянии редактирования один, на настоящей коллекции.

## 5. Правила, которым следует эта документация

**Утверждение без числа сюда не попадает.** Каждое «работает» несёт замер и то, откуда он взят: файл
снимка, команда, коммит.

**Отрицательный результат документируется рядом с положительным.** Два детектора стоят около 33%
precision; одно поле Tier 2 неизмеримо на нынешнем ground truth; один язык отдаёт около одного
запроса в секунду через HTTP. Это замеренные границы продукта, и они лежат в тех же таблицах, что и
хорошие числа.

**Отказ отвечать есть результат, а не ошибка.** Неподдерживаемый байткод, неопределённая проверка,
незнакомая коллекция — всё это типы, а не строки в логе. Инструмент, говорящий «не знаю» там, где не
знает, стоит больше того, который угадывает.

**Документация и код обязаны совпадать, и это проверяется.** Полное ревью однажды нашло документ,
сообщавший возможному партнёру, что ветка не начата, — через сутки после того, как её первая рабочая
версия была закончена. `make lint` теперь проверяет то, что может проверить машина, и те же правила
держат комментарии ([`TESTING.md`](./TESTING.md) §10).

**Гейт есть проверяемое условие.** «Детекторы работают» гейтом не является; порог агрегатной
precision против закоммиченного снимка или задокументированное отклонение от него — является.

**Английский канонический, а [`ru/`](./) — идентичное зеркало.** Обе стороны меняются одним коммитом,
и `make docs-check` сверяет деревья заголовков: перевод, молча отставший, хуже отсутствия перевода,
потому что читатель ему доверяет.

## 7. Чего этот указатель не покрывает

Он не пересказывает документы, которые перечисляет: пересказ есть вторая копия, устаревающая по
своему расписанию. Он не описывает работу в процессе — это [`ROADMAP.md`](./ROADMAP.md), единственный
здешний документ, которому позволено называть веху.
