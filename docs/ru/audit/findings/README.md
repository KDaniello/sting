# Журнал находок

Одна запись на гипотезу, включая опровергнутые. Отрицательный результат весит столько же, сколько
находка: он есть данные, а не потраченное время ([`../RULES.md`](../RULES.md) §3).

Молча исчезнувшая гипотеза есть дефект того же класса, что расхождение документации с кодом: три
раунда спустя никто не вспомнит, что уже проверялось, и цикл начинает переоткрывать одно и то же.

---

## 1. Как он ведётся

- Файл на гипотезу, пронумерованный и названный.
- Заводится **в момент формулировки гипотезы**, до пробы, — так фиксируется ожидаемый исход (гейт S1 в
  [`../GATES.md`](../GATES.md) §2).
- Обновляется по мере движения через [конвейер](../GATES.md) §3, никогда не переписывается задним
  числом.
- Статус двигается только вперёд: от гипотезы к одному из терминальных состояний.

## 2. Статусы

| Статус | Значение |
|---|---|
| гипотеза | сформулирована, проба не начата |
| скрининг | префильтр идёт |
| построение | строится доказательство или воспроизведение |
| опровергнута | опровергнута, с названным устойчивым отрицательным фактом |
| отрицательный | проба исполнилась корректно, дефекта нет — валидный отрицательный |
| вне скоупа | вне скоупа или известное поведение, с названным пунктом |
| подтверждена | доказательство показывает эффект, и каждый гейт пройден |
| отправлена | отправлено, с датой |
| принята или отклонена | ответ программы |

---

## 5. Чего этот журнал не держит

Он не держит эксплойта. Доказательство минимально и ограничено (гейт S4), и ничто отсюда не
публикуется до того, как исправление дойдёт до сети. Он не держит и ничего о цели вне скоупа, кроме
строки, записывающей, почему её отбросили.
